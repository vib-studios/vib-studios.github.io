vib-MC/Privacy policy

From the vib-MC Wiki, the documentation for a server nobody wrote by hand.

This page covers the website. For the licence and the disclaimers on the software, see vib-MC/Terms.

This site has no analytics. No trackers, no cookies, no accounts, no newsletter. What follows is exactly which requests your browser makes when you visit, and the three settings the site keeps on your own device.

The vib-MC website is a set of static files served by GitHub Pages. There is no backend, no database and no server that belongs to us, so there is nothing on our side that could record a visit in the first place.

Last updated: 5 September 2026.

What we collect

Nothing.

No analytics or tracking
The site loads no analytics script, no tag manager, no advertising pixel and no session recorder. You can confirm this by reading the page source: the only scripts are the ones served from this domain.
No cookies
The site sets no cookies of its own, which is why you are not being asked to dismiss a consent banner.
No accounts
There is nothing to sign up for. We never ask for your name, email address or payment details, so we hold no personal records about you.
Self-hosted fonts
Typefaces are served from this domain rather than a font CDN, so loading a page does not announce your visit to a third-party font provider.

Requests your browser makes

We collect nothing, but the site is hosted by GitHub and pulls some live data from GitHub. Those requests come from your browser, so GitHub can see them.

Hosting

The site runs on GitHub Pages. Serving a page necessarily involves your IP address and the request itself reaching GitHub's infrastructure, and GitHub may log that for security and abuse prevention. That processing is GitHub's, not ours, and is described in the GitHub Privacy Statement.

Live data from the GitHub API

Two small scripts, served from this domain, call the public GitHub API from your browser so you see current information rather than stale numbers.

Third-party requests, by page.
Page Requests it makes
Main article Current release details from api.github.com, the contributor list from the same API, and each contributor avatar from github.com.
Documentation Current release details from api.github.com.
Privacy policy, Terms None. These pages load the site's own scripts, but make no third-party requests.

These calls are unauthenticated and send no information about you beyond what any web request carries, such as your IP address and user agent. If a call fails, the page falls back to static content and keeps working.

Downloads

The download buttons point at release assets hosted by GitHub. Downloading the server jar is a request to GitHub, on GitHub's terms.

The bug report form

The bug report form on the main article does not send anything to us and does not submit to any server. It takes what you typed, builds a GitHub issue link with the text prefilled, and opens that link in a new tab. Nothing is published until you review it and submit the issue yourself on GitHub, where it becomes public. Do not put passwords, server IP addresses or other private details into a bug report.

What stays on your device

The site uses your browser's local storage for interface settings. This data never leaves your machine and is not readable by us.

Everything the site stores locally.
Key Set by What it holds
vibmc-wiki-theme Every wiki page Whether you picked the light or the dark theme. Absent means the site follows your operating system.
vibmc-skin Every page Whether you chose the wiki layout or the classic one, so you keep getting the layout you picked.
vibmc-blueprint-v2 Documentation Your work in progress in the plugin blueprint builder, so a reload does not throw away what you were configuring.
vibmc:contributors-collapsed Classic layout only Whether you collapsed the contributors rail on the classic home page.

A one-off session marker, vibmc-skin-hop, is written while the layout switch sends you from one layout to the other, and is cleared straight after. It is gone when you close the tab.

Clearing site data for this domain in your browser removes all of it. The site works normally without any of it.

The copy buttons write to your clipboard when you click them. They only ever write, and never read what is already on your clipboard.

Your choices

Because we hold no personal data, there is no account to delete and no export to request from us.

  • To remove what the site stores locally, clear site data for this domain.
  • To avoid the GitHub API calls entirely, block scripts for this domain. The pages remain readable.
  • For data GitHub holds about your visit or your GitHub account, contact GitHub under their privacy statement.
  • Anything you post in a public GitHub issue is public and is governed by GitHub's terms.

Other things worth stating

Links off this site

Links to GitHub, Adoptium and other sites are outside our control. Once you follow one, that site's own privacy policy applies.

The server software

This policy covers this website only. If you download and run vib-MC, it runs on your own machine and any data it writes, such as world files and logs, stays under your control and your responsibility as the server operator.

Children

The site is not directed at children and collects no personal information from anyone, regardless of age.

Changes to this policy

If the site's behaviour changes, this page changes with it and the date near the top is updated. The revision history is public in the website repository.

Questions about this policy can go to the issue tracker.
