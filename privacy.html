Privacy

This site has no analytics

No trackers, no cookies, no accounts, no newsletter. This page describes what this preview asks your browser to do.

Last updated: 18 November 2026

What we collect

Nothing. This preview is a set of static files. There is no backend, no database and no server that belongs to us.

No analytics or tracking

The page loads no analytics script, tag manager, advertising pixel or session recorder. The only script is the one served from this folder.

No cookies

The site sets no cookies of its own, which is why there is no consent banner.

No accounts

There is nothing to sign up for. We never ask for your name, email address or payment details.

Self-hosted fonts

Typefaces are served from this folder rather than a font CDN, so loading the page does not announce your visit to a third-party font provider.

Requests your browser makes

We collect nothing, but the page is served by a local preview server and asks GitHub for current release information.

Live release data

One small script calls the public GitHub API from your browser so the download block shows current release details. If the call fails, the page falls back to the values already in the markup. These calls are unauthenticated and send no information about you beyond what any web request carries, such as your IP address and user agent.

Downloads

The download buttons point at release assets hosted by GitHub. Downloading the server jar is a request to GitHub, on GitHub's terms.

Bug reports

The docs page links to GitHub's issue form. Nothing is submitted by this site. Anything you post in a public issue is public and governed by GitHub's terms.

What stays on your device

This preview does not use local storage. Copy buttons only write to your clipboard when you click them; they never read what is already on your clipboard.

Your choices

  • To avoid the GitHub API call entirely, block scripts for this domain. The pages remain readable.
  • For data GitHub holds about your visit or your GitHub account, contact GitHub under their privacy statement.
  • Anything you post in a public GitHub issue is public and is governed by GitHub's terms.

Other things worth stating

Links off this site

Links to GitHub, Adoptium and other sites are outside our control. Once you follow one, that site's own privacy policy applies.

The server software

This policy covers this website only. If you download and run vib-MC, it runs on your own machine and any data it writes, such as world files and logs, stays under your control and responsibility as the server operator.

Children

The site is not directed at children and collects no personal information from anyone, regardless of age.

Changes

If the site's behaviour changes, this page changes with it and the date at the top is updated.
