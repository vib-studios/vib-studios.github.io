privacy

This site has no analytics

No trackers, no cookies, no accounts, no newsletter. This page describes exactly which requests your browser makes when you visit, and the two settings the site keeps on your own device.

last updated: 5 September 2026

What we collect

Nothing. The vib-MC website is a set of static files. There is no backend, no database, and no server that belongs to us.

No analytics or tracking

The site loads no analytics script, no tag manager, no advertising pixel and no session recorder. You can confirm this by reading the page source: the only scripts are the ones served from this domain.

No cookies

The site sets no cookies of its own, which is why you are not being asked to dismiss a consent banner.

No accounts

There is nothing to sign up for. We never ask for your name, email address or payment details, so we hold no personal records about you.

Self-hosted fonts

Typefaces and icons are served from this domain rather than a font CDN, so loading the page does not announce your visit to a third-party font provider.

Requests your browser makes

We collect nothing, but the site is hosted by GitHub and pulls some live data from GitHub. Those requests come from your browser, so GitHub can see them.

Hosting

The site runs on GitHub Pages. Serving a page necessarily involves your IP address and the request itself reaching GitHub's infrastructure, and GitHub may log that for security and abuse prevention. That processing is GitHub's, not ours, and is described in the GitHub Privacy Statement.

Live data from the GitHub API

Two small scripts, served from this domain, call the public GitHub API from your browser so you see current information rather than stale numbers:

  • The home page and the docs page request the current release details from api.github.com.
  • The home page also requests the contributor list from the same API, and loads each contributor avatar from github.com.
  • This privacy page and the terms page make no such requests. They load only the small script that remembers which layout you chose.

These calls are unauthenticated and send no information about you beyond what any web request carries, such as your IP address and user agent. If a call fails, the page falls back to static content and keeps working.

Downloads

The download buttons point at release assets hosted by GitHub. Downloading the server jar is a request to GitHub, on GitHub's terms.

The bug report form

The bug report form on the home page does not send anything to us and does not submit to any server. It takes what you typed, builds a GitHub issue link with the text prefilled, and opens that link in a new tab. Nothing is published until you review it and submit the issue yourself on GitHub, where it becomes public. Do not put passwords, server IP addresses or other private details into a bug report.

What stays on your device

The site uses your browser's local storage for a few interface settings. This data never leaves your machine and is not readable by us.

Contributors panel

Remembers whether you collapsed the contributors rail, so it stays how you left it.

key: vibmc:contributors-collapsed

Plugin blueprint

Saves your work in progress in the plugin blueprint builder on the docs page, so a reload does not throw away what you were configuring.

key: vibmc-blueprint-v2

Layout

Remembers whether you chose the wiki layout or this classic one, so you keep getting the layout you picked.

key: vibmc-skin

Theme

Remembers whether you picked the light or the dark theme in the wiki layout. Absent means the site follows your operating system.

key: vibmc-wiki-theme

Clearing site data for this domain in your browser removes all of them. The site works normally without any of them. A one-off session marker, vibmc-skin-hop, is written while the layout switch moves you between layouts and is cleared straight after.

The copy buttons write to your clipboard when you click them. They only ever write, and never read what is already on your clipboard.

Your choices

Because we hold no personal data, there is no account to delete and no export to request from us.

  • To remove what the site stores locally, clear site data for this domain.
  • To avoid the GitHub API calls entirely, block scripts for this domain. The pages remain readable.
  • For data GitHub holds about your visit or your GitHub account, contact GitHub under their privacy statement.
  • Anything you post in a public GitHub issue is public and is governed by GitHub's terms.

Other things worth stating

Links off this site

Links to GitHub, Adoptium and other sites are outside our control. Once you follow one, that site's own privacy policy applies.

The server software

This policy covers this website only. If you download and run vib-MC, it runs on your own machine and any data it writes, such as world files and logs, stays under your control and your responsibility as the server operator.

Children

The site is not directed at children and collects no personal information from anyone, regardless of age.

Changes to this policy

If the site's behaviour changes, this page changes with it and the date at the top is updated. The revision history is public in the website repository.

Questions about this policy can go to the issue tracker.
