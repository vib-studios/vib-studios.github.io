Release notes

vib-MC is a Minecraft server written entirely by AI, one prompt at a time. It connects, generates terrain, accepts clients from Minecraft 1.8 through 26.1.2 (excluding 1.16, 1.16.1 and 1.19.3), and has a working survival loop. No human wrote a line of it.

The whole thing ships as one jar. Drop it in a folder, run it with Java 8 or newer, and point a client at port 25565. There is no launcher, no installer and no control panel. Everything below is taken from the repository README, without a marketing layer on top: where something does not work yet, this page says so.

[edit] Overview

vib-MC implements the Minecraft server protocol directly rather than patching the vanilla jar. Networking runs through PacketEvents, which is what makes the wide client range possible: a 1.8 client and a 26.1.2 client both get a version of the world they understand.

What works

It starts
Every time, in roughly four seconds on ordinary hardware.
People can join
Handshake, login and spawn, from Minecraft 1.8 to 26.1.2, minus 1.16, 1.16.1 and 1.19.3.
Terrain generates
Procedural, seeded and deterministic: biomes, caves, ores, trees and a village at spawn.
Survival
Blocks break with drops, tools and physics. Crafting, smelting, hunger, drowning, storage and combat are all in.
The Nether and the End
Both dimensions are real and both are reachable. You build the portal yourself.
Plugin API
The interface exists and events fire. See the documentation.

What does not

  • Mobs. None yet. Players are the only entities the server sends.
  • The dragon fight. The End towers are scenery. Nothing spawns on them.
  • Three client versions. 1.16, 1.16.1 and 1.19.3 are not supported and are unlikely to be soon.

[edit] Installation

Requirements

  • Java 8 or newer. Check with java -version. Releases before v0.0.6 needed Java 21.
  • The vib-MC jar, from the releases page, or built yourself.
  • A Minecraft client on any supported version.
  • A JDK, only if you intend to build the server or write plugins.

Building from source

Two commands. The jar lands in build/libs/.

Terminal 
$ ./gradlew build
$ java -jar build/libs/vib-mc.jar

First run

The server binds to port 25565 and writes a server.properties next to the jar on first start. Stop it, edit that file, start it again: values are read at boot only. World data is written to world/, world_nether/ and world_the_end/.

[edit] Internal structure

Fourteen packages under net.vibmc, coaxed into existence with prompts and then patched with more prompts. 

net.vibmc
├─ server          makes it go
├─ network         talks to minecraft
├─ world           blocks and stuff
├─ world.gen       makes the ground
├─ world.storage   saves the ground
├─ world.structure villages and trees
├─ entity          things that move
├─ player          the people
├─ inventory       slots and windows
├─ crafting        recipes and smelting
├─ registry        minecraft data
├─ plugin          mod support
├─ command         slash commands
└─ permission      who can do what
