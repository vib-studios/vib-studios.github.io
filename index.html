02 — Under the hood

Fourteen packages.
One jar.

No installer, no control panel, no account. Drop the jar in a folder and run it. Everything the server needs is inside that one file.

Server core

  • Handshake & login

    Players connect from a long list of client versions.

  • Player manager

    Sessions, positions, game modes and permissions.

  • World manager

    Worlds, chunks, blocks and deterministic generation.

  • Tick loop

    Start and end events that plugins can hook into.

World & play

  • Biomes & caves

    Seeded terrain with caves, ores and trees.

  • Village at spawn

    A generated place to start, not an empty plain.

  • Nether & End

    Both dimensions are reachable when you build the portal.

  • Survival loop

    Persistent state across restarts. Still early, still improving.

Tools for builders

  • Console commands

    /help, /tp, /gamemode, /give, /save-all and more.

  • Plugin loader

    Drop a jar into plugins/ and it loads on restart.

  • Event system

    Join, quit, chat and tick events, with cancellable chat.

  • server.properties

    Port, world name, seed, view distance and online mode.

03 — Extend it

A plugin is a jar,
a yml and one class

That is the whole contract. Extend VibMCPlugin, override onEnable(), compile against the vib-MC jar, then drop the result into plugins/.

plugin.yml
name=MyPlugin
version=1.0.0
main=com.example.MyPlugin
description=Does a thing, sometimes
authors=you
public class MyPlugin extends VibMCPlugin {
    @Override
    public void onEnable() {
        getCommandManager().register(
            new Command("gmc", "Switch to creative mode", "/gmc", null) {
                @Override
                public boolean execute(CommandSender sender, String[] args) {
                    if (!sender.isPlayer()) return false;
                    ServerPlayer player = sender.getPlayer();
                    player.setGameMode(GameMode.CREATIVE);
                    player.sendMessage("{\"text\":\"You are now in creative mode.\"}");
                    return true;
                }
            });
    }
}
public class JoinListener implements Listener {
    @EventHandler
    public void onJoin(PlayerJoinEvent event) {
        event.getPlayer().sendMessage(
            "{\"text\":\"Welcome to the vibe.\"}"
        );
    }
}

// in onEnable():
getPluginManager().registerEvents(new JoinListener(), this);

Questions

Before you download

The practical answers. The longer version lives in the docs.

Which Java version do I need?
The server and plugins compile and run against Java 8 or newer. Recent Minecraft clients want more: 26.x asks for Java 25, so one current JDK covers both.
Which Minecraft versions work?
Anything from 1.8 to 26.1.2, except 1.16, 1.16.1 and 1.19.3. A vanilla launcher profile works. No mods, Forge or Fabric needed.
Is there mob AI?
Not yet. Players are the only entities the server currently sends. This is early development and the docs say so plainly.
Can I write plugins?
Yes. Drop a jar into plugins/ with a plugin.yml and a class extending VibMCPlugin. The docs include a working example and the full API surface.
Where do I change the port or seed?
In server.properties, generated on first run. It holds the port, world name, seed, view distance and online-mode switch. Defaults are port 25565, a blank seed, and online mode on.
Should I back up my world?
Yes. This is unpaid software in early development, written by an AI and provided as is. Keep a copy of anything you would be unhappy to lose.
