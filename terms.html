The licence

  • Study and modify the source, and run your modified version.
  • Redistribute copies, modified or not.

What it asks in return

Using the site

The site is a static set of pages hosted on GitHub Pages. A few plain expectations apply.

  • Do not attempt to disrupt the site or the infrastructure it runs on.
  • Do not present modified copies of the site as the official vib-MC site.
  • The bug report form opens a public GitHub issue. Do not paste passwords, tokens or private server details into it.
  • Contributions and issues on GitHub are also subject to GitHub's terms and the project's repository rules.

Site text and images are part of the project repository and are covered by the same licence. The name vib-MC and the project's marks may be used to refer to the project truthfully, but not in a way that implies endorsement of a fork or an unrelated product.
