Requirements

What you need before anything else. Keep it simple.

Java 8 or newer

Both the server and plugins compile and run against Java 8+. Recent Minecraft clients want more: 26.x asks for Java 25, so one current JDK covers the server and the game.

The vib-MC jar

Grab the latest release jar from the downloads section. That is the whole server — no extra files to hunt down. Current stable: v0.0.7.

A Minecraft client

Anything from 1.8 to 26.1.2, except 1.16, 1.16.1 and 1.19.3. A vanilla launcher profile works. No mods, Forge or Fabric.

Only for plugins: a JDK

Running the server needs a JRE. Compiling plugins needs a full JDK and the vib-MC jar on the classpath. Gradle is optional — javac works fine.

Run the server

Two commands, zero configuration. The first run generates everything it needs.

# put vib-mc.jar in an empty folder
$ java -jar vib-mc.jar
$ java -jar vib-mc.jar

What happens

The server binds to 0.0.0.0:25565, generates a server.properties, and opens a plugins/ folder. Join with any supported client on localhost.

Config

server.properties holds the port, world name, seed, view distance and online-mode switch. Defaults are port 25565, a blank seed so each new world is random, and online-mode: true.

Server console

The console accepts the same commands as players. Click one to copy it.

Write a plugin

A plugin is a jar dropped into plugins/. It ships a plugin.yml and one class that extends VibMCPlugin. That is the whole contract.

1. plugin.yml

Lives at the root of the jar, read as a Java properties file. Only name, version and main are required.

name=MyPlugin
version=1.0.0
main=com.example.MyPlugin
description=Does a thing, sometimes
authors=you

2. The main class

Extend VibMCPlugin, override onEnable(), compile against the jar, drop the result into plugins/.

javac -cp vib-mc.jar -d out src/com/example/MyPlugin.java
jar cf MyPlugin.jar -C out . plugin.yml

3. Listening to events

Implement Listener, annotate methods with @EventHandler, then register them in onEnable().

public class JoinListener implements Listener {
    @EventHandler
    public void onJoin(PlayerJoinEvent event) {
        event.getPlayer().sendMessage("{\"text\":\"Welcome to the vibe.\"}");
    }
}

Events

PlayerJoinEvent, PlayerQuitEvent, cancellable ChatEvent, and TickEvent.Start / .End on every server tick.

Report a bug

Keep it short. Include the version, what you expected, what happened, and the steps to reproduce it. Do not paste passwords, tokens or private server details.
